## Weather Data Analysis and Visualization
This project is my final project for DATS 2102: Data Visualization for Data Science at The George Washington University.

### Project Overview
The goal of this project was to explore and analyse weather data to identify meaningful patterns, trends, and relationships between key weather variables. Using Python-based data analysis and visualisation tools, I worked with a weather dataset containing variables such as temperature, humidity, rainfall, and wind speed.

This project demonstrates my ability to clean data, perform exploratory data analysis, create visualisations, and communicate insights clearly through data storytelling.

### Objectives
- Explore a real-world weather dataset
- Clean and prepare the data for analysis
- Identify trends and patterns in weather variables
- Analyse relationships between variables such as temperature, humidity, rainfall, and wind speed
- Present findings using effective data visualisations

### Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Dataset
The dataset used in this project contains weather-related observations, including:
- Temperature
- Humidity
- Rainfall
- Wind Speed
- Date/Time information

### Methodology
1. Data Cleaning
I began by preparing the dataset for analysis. This included:
- Checking for missing values
- Removing duplicate records
- Standardising column names and data formats
- Ensuring variables were in appropriate data types for analysis
2. Exploratory Data Analysis
After cleaning the data, I conducted exploratory data analysis to better understand the dataset. This included:
- Generating summary statistics
- Examining the distribution of key variables
- Identifying trends, variability, and unusual observations
- Investigating relationships between different weather factors
3. Data Visualisation
To communicate findings effectively, I created multiple visualisations, such as:
- Line charts to show changes in weather variables over time
- Histograms to examine the distribution of variables
- Scatter plots to explore relationships between variables
- Heatmaps to identify correlations among weather features

### Key Insights
Through this project, I was able to identify several meaningful insights from the weather dataset, including:
- Trends and fluctuations in temperature over time
- Relationships between humidity and rainfall
- Correlations between different weather variables
- Potential anomalies or unusual patterns in the data
- These findings show how visualisation can make complex datasets easier to interpret and support data-driven understanding.
